Website portofolio pribadi yang dibangun dengan **Next.js 15 (App Router)**. Menampilkan perjalanan karier, proyek pengembangan web (Full Stack), desain UI/UX, serta integrasi statistik kontribusi GitHub.

🔗 **Live Demo:** [mrdhkrnwn.vercel.app](https://mrdhkrnwn.vercel.app/)

---

## ✨ Fitur Utama

* **Responsive & Modern UI:** Desain minimalis yang dioptimalkan untuk perangkat mobile dan desktop.
* **Dark Mode Support:** Transisi halus antara mode terang dan gelap.
* **Smooth Animations:** Didukung oleh `framer-motion` untuk pengalaman yang interaktif.
* **GitHub Dashboard:** Integrasi statistik kontribusi GitHub secara real-time.
* **Bilingual Support:** Tersedia dalam Bahasa Indonesia dan English.

---

## 🛠️ Tech Stack

### **Frontend & Framework**
* **Framework:** [Next.js 15](https://nextjs.org/) (React 19)
* **Styling:** [Tailwind CSS 4.0](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)
